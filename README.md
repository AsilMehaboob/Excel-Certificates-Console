# Excel Certificates Console

## Overview

Excel Certificates Console is a comprehensive web-based administrative tool designed to streamline and automate the process of generating course and event certificates. Built with Next.js, this application provides an intuitive interface for certificate administrators to manage templates, import participant data, and generate high-quality SVG/PDF certificates in bulk.

## Core Features

- **Bulk Data Import**: The application supports importing participant data (such as names and email addresses) via direct copy-pasting, minimizing manual data entry.
- **Dynamic Data injection**: Automatically binds imported participant data to placeholders within the SVG templates for seamless generation.
- **Certificate Preview**: Administrators can preview the generated certificates using the first record of the imported data to ensure correct formatting and alignment before committing to a full batch generation.
- **API-Driven Generation**: Utilizes customized Next.js API endpoints to handle background generation and processing of certificates.
- **Modern UI**: Designed with a focus on user experience and productivity, using modern web standards.

## Technical Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Data Processing**: Custom parsing for tabular participant data

## Getting Started

### Prerequisites

Ensure you have Node.js and npm (or yarn/pnpm) installed on your system.

### Installation

1. Clone the repository to your local machine.
2. Navigate to the project directory:
   ```bash
   cd excel-certificates-console
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```

### Development Server

To run the application locally in development mode:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:3000` to access the console. The application will automatically reload if you make edits to the source code.

## Usage Guide

1. Navigate to the certificate generation section within the application.
2. Upload your base SVG certificate template.
3. Provide the necessary event details, such as the event ID or event name.
4. Import your participant list containing columns for Name and Email.
5. Review the preview generated by the system.
6. Confirm and initiate the bulk certificate generation.

## Project Architecture

The codebase is organized following standard Next.js conventions:
- `/app`: Contains all pages, layouts, and API routes.
- `/components`: Contains reusable UI components.
- `/lib`: Utility functions and shared business logic.

## Deployment

The application is optimized for deployment on Vercel. Connect your Git repository to Vercel for automatic deployments upon pushing to the main branch. Alternatively, build the project manually using `npm run build` and start the production server with `npm run start`.
